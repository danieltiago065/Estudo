# 📊 Sales Performance Dashboard - Excel

Dashboard executivo de análise de vendas desenvolvido 100% em Excel utilizando Power Query, Power Pivot, Tabelas Dinâmicas e VBA.

---

# 🚀 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de praticar:

- ETL com Power Query
- Modelagem de dados
- Criação de KPIs
- Dashboards executivos
- Visualização de dados
- Automação com VBA
- Análise de vendas

---

# 🛠️ Tecnologias Utilizadas

- Microsoft Excel
- Power Query
- Power Pivot
- VBA
- Tabelas Dinâmicas
- Pivot Charts

---

# 📂 Base de Dados

Dataset utilizado:

Superstore Sales Dataset (Kaggle)

Contendo informações de:
- vendas
- lucro
- clientes
- categorias
- regiões
- produtos
- datas

---

# 📈 Visualizações Desenvolvidas

## Dashboard Executivo

- KPIs dinâmicos

- Vendas por categoria
- Lucro por região
- Top produtos

---

# 🔄 Processo de ETL

O tratamento dos dados foi realizado utilizando Power Query:

- padronização de datas
- correção de tipos de dados
- remoção de linhas em branco
- criação de colunas auxiliares
- criação da coluna AnoMes
- modelagem dimensional

---

# 🧠 Modelagem de Dados

Estrutura desenvolvida:

- F_Vendas
- D_Clientes
- D_Produtos
- D_Regiao
- D_Calendario

Relacionamentos realizados via Power Pivot.

---

# ⚙️ Automação VBA

Foi desenvolvido um template automatizado em VBA para:

- criação automática do dashboard
- criação de cards KPI
- geração automática de gráficos
- padronização visual
- estrutura executiva reutilizável
